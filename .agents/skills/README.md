# Maintainer skills

Curated, editable copies of engineering skills from [mattpocock/skills](https://github.com/mattpocock/skills) (MIT, Copyright (c) 2026 Matt Pocock). See `NOTICE.md`. The `pr` skill also credits the Humanlayer `show-me` skill (Dex Horthy).

These files guide coding agents that maintain Lingxi. They are not the product skill packs stored in the database.

## Included

- `setup-lingxi` — issue tracker and domain-doc layout for this repo
- `grill-with-docs` — design interview that writes glossary entries and ADRs
- `domain-modeling` — glossary and ADR discipline
- `codebase-design` — module, interface, depth, and seam vocabulary
- `tdd` — red-green loop at the HTTP seam
- `diagnosing-bugs` — feedback loop, with Lingxi secret redaction
- `implement` — build from a spec, then review
- `code-review` — standards axis and spec axis
- `pr` — pull request body shape

## Left upstream on purpose

Triage, tickets, specs, wayfinder, wizard, prototype, research, ask-matt, the productivity pack, misc installers, and `setup-ts-deep-modules`. Lingxi stays one Node package. Do not add dependency-cruiser or a `src/packages` tree unless a task asks for that.
