# Domain docs

Layout: single-context.

- Glossary: `GLOSSARY.md` at the repository root.
- ADRs: `docs/adr/NNN-title.md`.

Read `GLOSSARY.md` before introducing a name for a gateway concept. When a term is settled, update the glossary in the same change. Keep implementation, routes, and configuration out of the glossary.

Write an ADR only when the decision is hard to reverse, surprising without the context, and the result of a real trade-off.
