# Issue tracker

Issues and pull requests for Lingxi live on GitHub: https://github.com/jonycw/Lingxi

Use the `gh` CLI for reads (`gh issue view`, `gh pr view`). The default base branch for gateway work is `lingxi-gateway`.

PRs as a request surface: off. Do not pull external pull requests into a triage queue unless someone changes this file.

Do not put an upstream key, an admin token, or a customer `lx_` key in an issue, a pull request, or a commit.
